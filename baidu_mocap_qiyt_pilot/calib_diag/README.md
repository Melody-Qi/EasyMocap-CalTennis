# calib_diag — 三相机标定诊断与验证脚本

用于回答两个问题：**标定到底准不准**，以及**两套标定是真不同还是只差世界坐标系**。

运行前需要：`numpy`、`opencv-python`、`torch`（读 GVHMR 的 `vitpose.pt`）；
依赖 `~/pilot_3cam/triang_3cam_pilot.py` 中的 `parse_opencv_yml` / `triang_nview`。

## 脚本清单

| 脚本 | 作用 | 关键输出 |
|---|---|---|
| `diag_cam2_final.py` | 逐相机比较「单独 solvePnP 解」与「`final/` 里实际在用的位姿」的重投影残差 | 暴露哪一路的位姿已经不拟合自己的地标 |
| `diag_cam2_ransac.py` | 对每路球场点做 RANSAC PnP，列出被剔除的错标点及其残差 | 坏点清单（cam2 的 14 点里有 6 个错标） |
| `judge_cam2_pose.py` | **决定性裁判**：用「cam1+cam3 三角化出的人体关节」投影到 cam2，比较两个候选位姿谁对 | 47.6 px vs 1246.2 px，差 26 倍 |
| `compare_relpose.py` | 比较两套标定的**相对位姿不变量**（相机两两之间的 R、\|t\|） | 判断是否只是世界坐标系定义不同 |
| `compare_two_calibs.py` | 比较两套标定的内参与相机光心 | 焦距、畸变、光心位置差异 |

## 三条方法论（可复用到其他多相机项目）

1. **自洽重投影误差会骗人。** 它只说明两条射线相交得干不干净；若某路外参有残余系统偏差，交点整体偏移而自洽误差照旧很低。评相机对必须**留一路 hold-out 相机**做检验，并按距离归一化（`e·z`）后再比较。
2. **判断两套标定是「真不同」还是「只差世界系」，用相对位姿不变量。** 相机两两之间的 `R_rel` 和 `|t|` 与坐标系无关；若是纯坐标系差异，这三项都应接近 0。
3. **判断某路相机位姿对不对，要找独立于标定输入的第三方数据源。** 本项目中：球场点是标定输入，人体 ViTPose 可作裁判（反之亦然）。两个数据源互斥，才能构成有效裁决。

## 已知问题（截至 2026-09-10）

- cam2 的位姿来自人体反解而非地标（其球场点 6/14 错标），与 ViTPose 同源，独立性受损
